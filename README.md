Финансовый трекер предназначен для отслеживания баланса, доходов и расходов, а также для просмотра информации о денежных средствах.

На главной странице отображаются общий баланс, наличные и безналичные средства, а также информация о расходах.

Реализованные возможности:
1. Переключение страниц с помощью обработчиков событий.
2. Выделение активной страницы в навигации.
3. Отображение компонентов в зависимости от выбранного раздела.
4. Вывод списка операций с помощью @for.
5. Использование track для идентификации элементов списка.
6. Условное отображение элементов через @if, @for.
7. Поиск и фильтрация операций по типу, категории, описанию и способу оплаты.
8. Привязка свойств и CSS-классов с помощью Property Binding и Class Binding.
9. Реактивное состояние страницы операций на основе Angular Signals: signal() для списка операций и параметров фильтрации.
10. Производные значения через computed(): количество всех операций, количество расходов и отфильтрованный список.
11. Удаление операции через update() с созданием нового массива без мутации исходного.
12. effect() для вывода количества операций в консоль при изменении списка.

Что было добавлено

1. Создан отдельный компонент карточки операции: 
    - Transaction — родительский компонент со списком операций.
    - TransactionCard — дочерний компонент карточки операции.
2. Для передачи данных от родителя к ребёнку
   использован input.required().
3. Для передачи события удаления использован output().
4. Массив операций хранится в signal().
5. Для удаления операций используется signal.update().
6. Для открытия и закрытия подробностей используется model().
7. Для передачи дополнительной HTML-разметки используется ng-content.

Результат:
Родительский компонент хранит все операции.
Дочерний компонент получает данные, отображает карточку и отправляет родителю событие удаления.

Инструкция по запуску
1. Склонировать репозиторий или скачать проект.
2. Открыть терминал в папке проекта.
3. Установить зависимости:
    
    npm install

4. Запустить приложение:
    
    ng serve или npm start

5. Открыть в браузере адрес:
    
    http://localhost:4200/
